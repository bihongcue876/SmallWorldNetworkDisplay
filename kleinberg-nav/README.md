# 小世界寻路

Kleinberg 可导航性模型的浏览器模拟。在一个 n×n 的环面网格上，每个节点连着四个近邻，还有一条按距离幂律抽出的长程边；搜索者每一步只看当前节点的邻居和目标方位，选离目标更近的节点前进——不搜索、不回头、不预知全局。长程边的指数 α 决定了这样的局部策略能走多快。

> 短路径存在，不等于短路径能被找到。这个模拟把这句话变成可以动手玩的东西。

## 页面在做什么

- **单次演示**：调 n 与 α，播放或单步看贪心路径；点画布选起点，按住 Shift 点选终点；右侧给出跳数 T、同对节点的最短路 ℓ 和效率比 T/ℓ。
- **四个预设**：α=0（长程边乱指）、α=1、α=2（Kleinberg 最优点）、α=3（长程边太短）。同一随机种子、同一对起终点，切换 α 直接对比。
- **批量实验**：小规模重复建图与路由，结果按配置哈希累积成表，可导出 CSV。
- **结论**：模型与路由规则的简明描述、三条文献定理（Kleinberg 2000 的 Theorem 2 / 3(a) / 3(b)）、临界点的推导梗概，以及本项目实测到的四条性质。地址栏 `#theory` 直接进入。

## 它说明的三件事

数据由仓库内的批量脚本生成，约 11 万次路由，n 覆盖 16 到 1024：

1. **成功率恒为 100%。** 本地边保证每步都有更近的邻居，严格贪心在这个模型里不会失败。可发现性的差别体现在跳数，不在能否到达。
2. **α=2 赢在增长率。** α=0 的平均跳数与 n^(2/3) 吻合（误差小于 2%），α=2 沿 log²n 增长；两条曲线在 n≈200 交叉，n=1024 时 α=2 只需 α=0 的 65%。
3. **最优点随规模右移但未到 2。** 使跳数最小的 α 从 n=16 时的 0 移到 n=512 时的 1.75——有限规模下最优指数偏小，与已有研究的结论一致。

## 本地运行

```bash
npm install
npm run dev        # 开发演示，默认 http://127.0.0.1:5173
npm run test       # 36 个单元测试
npm run build      # 构建纯静态产物到 dist/
npm run exp        # 批量实验，输出到 results/
```

构建产物是纯静态文件，GitHub Pages、Vercel、Netlify 或任意静态目录都能直接托管（基址已设为相对路径）。

## 技术与结构

Vite + TypeScript（vanilla，无框架）、Canvas 2D 渲染、Web Worker 跑批量，运行时零依赖。所有随机数来自显式种子（mulberry32），建图、长程边、源目标各用独立派生流，同一配置在浏览器与 Node 中结果逐位相同。

```
src/core/       算法核心：距离、分层采样、建图、贪心路由、BFS、统计
src/worker/     批量实验 Worker
src/web/        界面：状态、渲染、指标、说明浮层
scripts/        批量实验脚本
tests/          Vitest 单元测试
```
